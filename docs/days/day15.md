# Day 15：克隆仓库

## 学习目标

从远程复制一个完整项目到本地。

## 核心概念

`clone` 会下载仓库文件、提交历史，并自动配置远程地址。

## 常用命令

```bash
git clone https://github.com/your-name/your-repo.git
git remote -v
```

## 今日练习

1. 新建一个空目录。
2. 克隆自己的练习仓库。
3. 进入仓库后执行 `git remote -v`。
4. 执行 `git log --oneline` 查看历史。

## 检查点

你应该知道：克隆得到的不只是文件，还有完整的 Git 历史。
