# Day 09：切换分支

## 学习目标

熟练使用 `git switch`。

## 核心概念

切换分支会让工作区变成目标分支对应的文件状态。

## 常用命令

```bash
git switch main
git switch feature/notes
git switch -c feature/readme
```

## 今日练习

1. 在 `feature/notes` 分支创建一个文件并提交。
2. 切回 `main`。
3. 观察文件是否还在。
4. 再切回 `feature/notes` 对比变化。

## 检查点

你应该知道：不同分支可以拥有不同的文件内容和提交历史。
