# Day 11：解决冲突

## 学习目标

理解冲突为什么出现，以及如何手动解决。

## 核心概念

当两个分支修改了同一个文件的同一段内容，Git 不知道该保留哪一份，就会产生冲突。

冲突标记通常长这样：

```text
<<<<<<< HEAD
main 分支内容
=======
feature 分支内容
>>>>>>> feature/demo
```

## 解决步骤

1. 打开冲突文件。
2. 手动整理成最终想要的内容。
3. 删除冲突标记。
4. 执行 `git add`。
5. 执行 `git commit`。

## 今日练习

1. 在两个分支分别修改 `README.md` 的同一行。
2. 尝试合并制造冲突。
3. 手动解决冲突并提交。

## 检查点

你应该知道：解决冲突的关键是保留正确内容，而不是只删除标记。
