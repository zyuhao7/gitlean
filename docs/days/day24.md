# Day 24：整理提交记录

## 学习目标

了解交互式 rebase。

## 核心概念

交互式 rebase 可以整理最近几次提交，例如修改提交信息、合并多个小提交。

## 常用命令

```bash
git rebase -i HEAD~3
```

常见操作：

```text
pick   保留提交
reword 修改提交信息
squash 合并到上一个提交
```

## 今日练习

1. 连续做 3 个小提交。
2. 执行 `git rebase -i HEAD~3`。
3. 尝试把它们合并成一个提交。

## 检查点

你应该知道：整理历史只适合还没有共享出去的提交。
